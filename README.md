# Thiệp Chúc Mừng Sinh Nhật Bà — 20 Tháng 11

Trang web kỷ niệm ngày sinh nhật Bà (**20 tháng 11**) thiết kế theo phong cách **Thư Họa & Lụa Vàng** — ấm áp, trang nhã, chữ rõ ràng dễ đọc và giàu tương tác.

## Trải nghiệm nổi bật

- **Bì thư niêm sáp đỏ (20·11)**: Mở dấu sáp để mở tấm thiệp kèm hiệu ứng cánh hoa cúc và giai điệu hộp nhạc *Happy Birthday* (tổng hợp bằng Web Audio API).
- **Khu vực mở đầu & Tranh màu nước**: Minh họa hoa cúc vàng, cúc họa mi và ấm trà ấm áp, hiển thị thông điệp đặc biệt đúng ngày 20/11.
- **Nghi thức thổi nến sinh nhật**: Chiếc bánh hai tầng với 5 ngọn nến lung linh có thể chạm từng ngọn, bấm thổi tất cả, hoặc dùng micro để thổi tắt.
- **Lá thư tay gửi Bà**: Bức thư chân thành với kiểu chữ thư họa dịu mắt và nút **A+ Chữ lớn** phóng to chữ giúp Bà đọc thật thoải mái.
- **Sáu tấm lụa chúc thọ**: Chạm mở từng lời chúc (*Bình An, Sức Khỏe, Trường Thọ, Niềm Vui, Sum Vầy, Yêu Thương*) để mở khóa món quà thứ bảy đặc biệt.
- **Đêm thả đèn hoa đăng**: Thả thêm đèn hoa đăng mang lời chúc từ người thân (lưu tự động trên trình duyệt).

## Công nghệ sử dụng

- React 19 + TypeScript + Vite
- Web Audio API (nhạc hộp âm & hiệu ứng âm thanh)
- HTML5 Canvas (cánh hoa cúc bay dịu nhẹ & pháo hoa chúc mừng)
- Lucide Icons & Google Fonts (`Cormorant Garamond`, `Lora`, `Be Vietnam Pro`, `Dancing Script`)

## Chạy ở máy cá nhân

```bash
npm install
npm run dev
```
